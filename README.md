# TalentFlow AI ⚡

> A modern AI-assisted job platform focused on intelligent career matching and premium user experience.

Modern job board application built with React + Vite, focused on clean UI, responsive design, smooth interactions, and AI-inspired career insights.

---

## ✨ Features

| Feature                           | Description                                      |
| --------------------------------- | ------------------------------------------------ |
| 🤖 AI Match Score                 | AI-assisted compatibility scoring for every job  |
| 🎯 Skill Gap Analysis             | Highlights skills to improve before applying     |
| ✍️ Smart Cover Letter Suggestions | Generates personalized opening suggestions       |
| 💡 Job Insights                   | Extracts useful role and company information     |
| 🔖 Save Jobs                      | Persistent bookmarks using local storage         |
| 🔍 Smart Search                   | Search and filter across job listings            |
| 📊 Dashboard                      | Personalized activity and saved jobs overview    |
| 🌙 Dark/Light Mode                | Smooth animated theme transitions                |
| 📱 Fully Responsive               | Optimized for desktop, tablet, and mobile        |
| ⚡ Skeleton Loaders                | Smooth loading experience                        |
| 🎨 Modern UI System               | Glassmorphism-inspired interface with animations |

---

## 🛠 Tech Stack

```txt
React 18        → Frontend component architecture
Vite 5          → Fast development environment
Tailwind CSS    → Utility-first styling system
Framer Motion   → Animations and transitions
Zustand         → Lightweight state management
React Router    → Client-side routing
Lucide React    → Icon system
React Hot Toast → Notifications and alerts
date-fns        → Date utilities
```

## 🚀 Getting Started

### Prerequisites

* Node.js 18+
* npm 9+

### Installation

```bash
git clone https://github.com/your-username/talentflow-ai.git

cd talentflow-ai

npm install

npm run dev
```

Open:

```txt
http://localhost:5173
```

---

## ⚙️ Environment Variables

```bash
VITE_ANTHROPIC_API_KEY=your_api_key
```

The application also works completely with mock data if no API key is provided.
